# 🎓 Student Details Task

A simple and responsive **Student Details Management Form** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* Add student details through a form
* Name, Age, Gender, Course, and E-mail fields
* Real-time form validation
* Validates name, age, and email
* Save button is enabled only when all required fields are valid
* Student records are displayed in a table
* Delete student records
* Uses **Local Storage** to preserve student records
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 📋 Student Details

The form collects:

* **Name**
* **Age**
* **Gender**
* **Course**
* **E-mail**

The available courses include Python, JavaScript, Java, React, and Django.

## ⚡ JavaScript Functionality

JavaScript is used for:

* Real-time validation
* Form submission
* Adding student records
* Deleting records
* Rendering records in a table
* Storing data in browser Local Storage
